        Three rules decide whether a SIP survives

        From Groww's published help pages, checked 3–4 Nov 2026. Most first-time investors never see them.

        3 in a rowThree missed, failed or skipped instalments in a row cancel the SIP automatically.
        2 daysA skip or edit within 2 days of the debit doesn't count for that month.
        7 daysCancelling is locked within 7 days of the next instalment.

        How an answer is made

        Every question takes the same five steps. Nothing reaches the user without passing the last one.

        1. The momentA failed debit, a debit coming up, a blocked skip, or a Cancel tap opens GR-1 with this SIP loaded.
        2. Policy checkFund picks and predictions are declined by code, before any AI call.
        3. Rules engineCode calculates every date, deadline and option. The AI can't change them.
        4. AI explainsDrafts an answer using only the engine's facts, citing the rules it used.
        5. 7 checks Decides what's shownCode checks and an AI reviewer. Pass: the answer is shown. Fail: a safe fallback.

        What it will never do

        • Recommend funds or stocks
        • Predict returns or recovery
        • Use urgency or fear
        • Argue against cancelling
        • Act without the user
        • State a rule it can't confirm

        Limits of this demo

        • Sample data only. Buttons that would change a SIP show a demo notice.
        • Automatic retries, exact bank fees and fund-specific skip limits aren't documented by Groww, so the assistant says it can't confirm them.
        • Working days skip weekends but not bank holidays.
